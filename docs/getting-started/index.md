# Getting Started

Welcome! This section will help you get started with using and contributing to this knowledge base.

## Overview

This knowledge base is built with Jekyll and uses the Just the Docs theme. It's designed to be:

- **Easy to navigate**: Tree-view navigation with collapsible sections
- **Easy to search**: Full-text search across all documentation
- **Easy to read**: Dark theme optimized for long reading sessions
- **Easy to contribute**: Simple Markdown files

## What's Inside?

### Documentation Structure

The knowledge base is organized into three main sections:

1. **Getting Started**: Introduction and setup guides (you are here!)
2. **Guides**: Step-by-step tutorials and how-to guides
3. **Reference**: Technical reference documentation and code examples

## Navigation

Use the sidebar on the left to browse through different sections. Click on sections with arrows to expand/collapse them.

## Search

Use the search bar at the top to find specific topics. The search is instant and searches through all content.
