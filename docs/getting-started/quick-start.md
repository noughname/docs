# Quick Start Guide

Get up and running with this knowledge base in just a few minutes.

{: .fs-6 .fw-300 }

## What You'll Learn

In this quick start, you'll learn how to:
- Navigate the knowledge base effectively
- Use the search functionality
- Find relevant documentation quickly
- Understand the documentation structure

---

## 1. Browse the Navigation

The sidebar on the left contains all available documentation organized hierarchically:

- **Getting Started**: Introduction and setup guides
- **Guides**: Step-by-step tutorials
- **Reference**: Code snippets and configuration examples

{: .note }
Click on sections with arrows (▸) to expand and see child pages.

## 2. Use the Search

The search bar at the top is your fastest way to find information:

1. Click the search bar or press `Ctrl/Cmd + K`
2. Type your query (e.g., "python", "docker", "configuration")
3. Press `Enter` or click a result to navigate

{: .highlight }
> **Pro Tip**: Search looks through all page titles, headings, and content, so you can use natural language queries.

## 3. Navigate Between Pages

Each page includes helpful navigation elements:

- **Breadcrumbs** at the top show your current location
- **Previous/Next** links at the bottom help you move through sections
- **Back to Top** button appears when you scroll down
- **Table of Contents** on the right (on wider screens) for quick jumps

## 4. Copy Code Examples

All code blocks include a copy button (appears on hover):

```python
# Example: Just hover and click the copy button
def hello_world():
    print("Hello, Knowledge Base!")
```

## 5. Explore Different Content Types

This knowledge base includes various types of documentation:

| Type | Description | Example Location |
|------|-------------|------------------|
| **Tutorials** | Step-by-step learning guides | Guides section |
| **How-To Guides** | Task-focused instructions | Guides section |
| **Reference** | Technical details and snippets | Reference section |
| **Explanations** | Conceptual overviews | Throughout |

---

## Common Tasks

### Finding a Code Snippet

1. Go to **Reference** section in sidebar
2. Browse by language or tool
3. Or use search with language name (e.g., "Python JSON")

### Learning a New Concept

1. Start with **Getting Started** for fundamentals
2. Move to **Guides** for hands-on tutorials
3. Refer to **Reference** for quick lookups

### Troubleshooting

1. Use search with error message or problem description
2. Check the Getting Started section for common issues
3. Review relevant guide for detailed context

## Keyboard Shortcuts

Make navigation even faster with keyboard shortcuts:

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + K` | Focus search |
| `/` | Focus search (alternative) |
| `Esc` | Close search |
